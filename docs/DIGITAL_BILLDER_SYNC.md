# Digital Billder 新着取込

## 操作

1. `起動.bat` → 管理メニュー → **Digital Billder 新着取込** を開きます。
2. 初回は **ログイン設定** でメールアドレスとパスワードを保存します。
3. **新着確認** で未確認の請求を取得します。初回は現在閲覧できる請求が候補になります。
4. 必要な請求を選び、**選択を取込** を押します。Ctrl / Shiftで複数選択できます。
5. 誤請求など不要な請求は選択して **選択を除外** を押します。

除外済みの請求は次回の候補に出ません。**除外済みを表示** → 選択 → **選択の除外解除** で戻せます。
一覧を見ただけでは処理済みにしません。取込・除外を決めるまで候補に残します。

## 取得範囲と処理

- 接続先は `https://purchases.digitalbillder.com/invoices/applications` です。
- ログインしたユーザーが「担当する請求書」で閲覧できる請求のうち、破棄済みを除きます。
- 台帳に登録済みのID、過去に取込済み・除外済みと記録したIDは新着候補から外します。
- 新着確認では、対象一覧のCSVを毎回取得してIDを照合します。PDFは取得しません。候補はローカルDBに保存され、アプリを閉じても確認を続けられます。
- 取込時にCSVを再取得し、選択した請求の内容が変わっていないことを確認します。
- PDFは選択した未取込請求だけを取得します。Web一覧のページごとに対象行を選び、選択行のCSVでIDと内容の一致を確認してから、その行のファイルZIPを取得します。取込済み・除外済み・未選択の請求PDFを全件ZIPとして再取得することはありません。
- 複数の添付PDFは元のファイル名と内容を保持します。取得したZIPの請求IDが選択IDと一致しない場合、登録せず停止します。取得用の一時CSV・ZIPは処理後に削除します。
- Webの並び順・ページ構造が変わり、選択CSVで対象を確認できない場合は停止します。全件PDF取得への自動切替は行いません。
- ダウンロードや読み取りに失敗しても取込済みにしません。台帳登録の途中失敗はDBの更新を取り消します。
- PDF保存後のDBエラーでは、DBに紐付かないPDFが残る場合があります。再試行時は同一内容のファイルを再利用します。
- Digital Billder側の請求内容・承認・保管・破棄状態は変更しません。除外はこのアプリ内だけの記録です。

## ログイン情報

パスワードはWindowsの資格情報マネージャーに、サービス名 `Digitalbillder_GR/purchases.digitalbillder.com` で保存します。
メールアドレスはアプリ設定に保存します。認証済みブラウザのプロファイルやCookieはファイルに保存せず、取得ごとにログインします。
ログイン情報を変更する場合は **ログイン設定** で保存し直してください。

## セットアップと制限

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium --only-shell
```

- Windowsの資格情報マネージャーを利用できる環境が必要です。
- 初回のブラウザ実行環境セットアップにはダウンロードが必要です。
- 追加認証やCAPTCHA、ログイン方式・画面構造の変更があると自動取得は停止します。
- サイトの検索更新には待ち時間があるため、条件変更後に待機してからダウンロードします。
- ZIPは従来の取込と同じ制限（500MB、PDF 1ファイル100MB、合計1GB、1000PDF）があります。
- 重複候補・アーカイブ工事の請求は自動取込を中止します。既存のCSV + zip取込画面で確認できます。
- 定期実行はしません。**新着確認** と **選択を取込** を押したときに実行します。
