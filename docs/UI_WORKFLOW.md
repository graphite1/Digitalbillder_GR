# 管理画面UIの分離運用

通常版は `main`、管理画面の検討版は `codex/management-ui` の別worktreeです。

- 通常版: `C:/Users/rinnt/Documents/Codex/Digitalbuilder＿GR`
- UI検討版: `C:/Users/rinnt/Documents/Codex/Digitalbuilder_GR-ui-preview`

UIを変更する対象は `invoice_manager/ui/main_window.py` の管理メニューだけです。請求一覧・詳細・予算・履歴画面の配置、全体テーマは変更しません。操作数と一覧性を優先し、全操作が一画面で見える構成を比較します。

## 採用状況

利用者の採用指示により、プレビュー版の管理メニューを通常版へ反映済みです。「取込」「集計・予算」「設定」と下部の操作ボタンを一画面に並べます。両作業フォルダーの管理画面コードは同じ内容になっています。

## 現在の未コミット変更

機能追加がまだコミットされていないため、検討版には通常版と同じ機能コードを複製しています。ブランチのGit差分にはその機能追加も含まれます。UI専用の追加差分は、複製した時点の通常版との比較で管理します。ブランチを作っただけで未コミット変更が分離されるわけではありません。

コミット・プッシュは利用者の明示指示があるまで行いません。今後のUI変更も検討版で確認し、採用指示を受けた範囲だけ通常版へ反映します。

## 起動とデータ

各フォルダーの `起動.bat` から起動できます。検討版のPython環境は通常版の `.venv` をジャンクションで参照し、同じ依存ライブラリを使います。

アプリのデータ保存先はそれぞれのフォルダーの `data/` です。実際の台帳・PDF・予算原本・ログイン設定は検討版へコピーしていません。検討版は空の台帳から起動します。Windowsの資格情報保管領域自体はPC共通なので、UI確認にはログインや実データ取込を使わないでください。

開いている旧画面にはファイル更新が反映されません。取得や編集中の処理を終えてから閉じ、使用するフォルダーの `起動.bat` を起動し直します。
